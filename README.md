# Web Jugaad Agency website

Static site (plain HTML, CSS and JavaScript in one file). No build step.

Files:
- index.html: the complete website (design, animations, images, videos are all inside this file)
- 404.html: sends mistyped URLs back to the home page
- .nojekyll: tells GitHub Pages to serve the files as they are

Deploy: upload these files to a public GitHub repository, then Settings > Pages > Deploy from a branch > main / (root).
